# 나만의 시작 페이지

바로가기, 할 일, 습관, 메모, 뉴스, 자주 방문한 사이트를 한 화면에 모은 크롬 새 탭 확장 프로그램입니다. 빌드 과정 없이 순수 HTML/CSS/JS로 작성되었으며, 모든 데이터는 `chrome.storage.local`에 저장됩니다. AI 뉴스 브리핑 기능을 사용할 경우에 한해 API 키와 요청이 동국 AI CHAT API Gateway로 전송됩니다(자세한 내용은 [참고](#참고) 섹션 참조).

## 기능

- **바로가기** — 자주 가는 사이트를 추가/삭제하고 드래그로 순서를 바꿀 수 있는 바로가기 목록. 기본값으로 Gmail, Notion, GitHub가 등록되어 있으며, 새 탭 화면에서 항상 맨 앞에 고정됩니다 (`shortcuts.js`).
- **할 일** — 항목 추가, 완료 체크, 삭제가 가능한 간단한 할 일 목록 (`todo.js`).
- **습관** — 매일 체크하는 습관 목록. 최근 7일 점 표시와 연속 기록(🔥streak)을 보여주고, 습관 이름을 클릭하면 월간 히트맵으로 상세 기록을 확인할 수 있습니다. 기본은 숨김 상태이며 "+ 모듈 추가"로 켤 수 있습니다 (`habit.js`).
- **메모** — 제목과 본문을 자유롭게 적을 수 있는 메모 카드로, 입력 후 자동 저장됩니다. 여러 개의 메모 카드를 동시에 추가할 수 있습니다 (`notes.js`).
- **뉴스** — Google 뉴스 RSS 피드(`news.google.com`)를 불러와 최신 기사 8건을 보여줍니다. 전체/대한민국/세계/경제/IT·과학/연예/스포츠/건강 분야 칩(다중 선택 가능)으로 관심 분야를 선택하면 해당 분야 피드로 데이터를 가져오고 선택은 저장됩니다. 각 기사에는 언론사 파비콘 썸네일이 함께 표시됩니다. 15분간 캐시되며(선택한 분야 조합별로 별도 캐시) 새로고침 버튼으로 즉시 갱신할 수 있습니다 (`news.js`).
- **AI 브리핑** — 뉴스 카드의 "AI 요약" 버튼을 누르면 동국 AI CHAT API Gateway를 통해 Claude(`claude-sonnet-5`)가 자체 웹 검색 도구(`web_search`)로 최근 1주일 내 취업/노동시장, 부동산/주거, 재테크/금융, IT/AI 분야의 주요 뉴스를 직접 검색해 카테고리별로 정리하고 참고 자료 링크와 함께 브리핑을 생성합니다. RSS로 가져온 헤드라인 목록과는 별개로 동작하며(분야 칩 필터의 영향을 받지 않음), 브리핑은 하루 단위로 캐시되어 같은 날 다시 열면 재요청 없이 보여줍니다. 최초 사용 시 API 키 입력 모달이 뜨며, 키는 `chrome.storage.local`에만 저장됩니다 (`news.js`).
- **자주 방문** — 크롬의 `topSites` API로 자주 방문한 사이트를 추천합니다. 이미 바로가기에 등록된 사이트는 제외되며, 항목의 `+` 버튼으로 바로가기 목록에 바로 추가할 수 있습니다. 기본은 숨김 상태이며 "+ 모듈 추가"로 켤 수 있습니다 (`mostvisited.js`).
- **모듈 배치** — 별도 설정 페이지 없이 새 탭 화면에서 바로 모듈(할 일/습관/메모/뉴스/자주 방문)을 관리합니다. 각 모듈에 마우스를 올리면 좌상단 드래그 핸들(⠿)과 우상단 숨기기 버튼(×)이 나타나며, 핸들을 드래그해 원하는 위치로 끌어다 놓으면 순서가 바뀝니다(바로가기는 항상 맨 앞에 고정되어 순서 변경 대상에서 제외). 숨긴 모듈은 카드 목록 끝의 "+ 모듈 추가" 타일을 눌러 다시 표시할 수 있고, 메모는 숨기기 대신 항상 새 카드를 추가하는 방식으로 동작합니다 (`modules.js`, `layout.js`).
- **설정(드래그 정렬 켜기/끄기)** — 화면 우상단 "설정" 토글로 모듈 드래그 정렬 기능 전체를 껐다 켤 수 있습니다(바로가기 자체의 순서 변경은 이 설정과 무관하게 항상 가능). 실수로 카드를 옮기는 것을 방지하고 싶을 때 끄면 됩니다 (`settings.js`).

## 로컬에서 실행하기 (개발자 모드)

1. 크롬 주소창에 `chrome://extensions`를 입력합니다.
2. 우측 상단의 "개발자 모드"를 켭니다.
3. "압축해제된 확장 프로그램을 로드합니다"를 클릭합니다.
4. 이 프로젝트 폴더(`newtab-extension`)를 선택합니다.
5. 새 탭을 열면 시작 페이지가 적용됩니다.

빌드 과정이 없으므로 파일을 수정한 뒤 바로 확인할 수 있습니다.

- **JS/CSS 수정 후**: `chrome://extensions`에서 이 확장 프로그램의 새로고침(⟳) 아이콘을 클릭한 다음, 열려 있던 새 탭을 닫고 다시 열어야 변경사항이 반영됩니다.
- **`manifest.json` 수정 후**: 위와 동일하게 새로고침이 필요합니다. 권한이나 `host_permissions`을 바꿨다면 크롬이 재승인을 요구할 수 있습니다.
- **HTML만 수정한 경우**: 새 탭을 다시 열기만 해도 반영됩니다 (확장 프로그램 새로고침 불필요).

## 테스트 방법

자동화된 테스트 스위트는 없으며, 수동으로 새 탭 페이지를 열어 기능별로 확인합니다.

1. 새 탭(Ctrl/Cmd+T)을 열고 페이지 위에서 마우스 우클릭 → "검사"로 DevTools를 엽니다.
   - **Console** 탭에서 에러가 없는지 확인합니다 (특히 `news.js`의 fetch 실패 로그).
   - **Network** 탭에서 새로고침 버튼 클릭 시 `news.google.com/rss...` 요청이, AI 요약 클릭 시 `factchat-cloud.mindlogic.ai` 요청이 정상적으로 이루어지는지 확인합니다.
   - **Application → Storage → Extension Storage**(또는 `chrome.storage.local`)에서 저장된 값(`todos`, `habits`, `shortcuts`, `notes:<id>`, `moduleConfig`, `dndEnabled`, `news_cache:<분야조합>`, `news_pref_topics`, `news_ai_dongguk_key`, `news_ai_summary_cache`)을 직접 확인/삭제할 수 있습니다.
2. 기능별 체크리스트:
   - **바로가기**: "+ 추가" 버튼으로 이름/URL을 등록하고, 클릭 시 해당 사이트로 이동하는지, ×로 삭제가 되는지, 드래그로 순서를 바꿀 수 있는지 확인합니다. 새 탭을 다시 열어도 목록/순서가 유지되는지 확인합니다(영속성 테스트).
   - **할 일**: 항목 추가 후 Enter, 체크박스로 완료 처리, 삭제 버튼 동작, 남은 개수 표시(`n개 남음`)가 올바른지 확인합니다.
   - **습관**: 습관 추가 후 오늘 체크박스를 켜면 연속 기록(🔥)이 올라가는지, 이름을 클릭하면 월간 히트맵 모달이 열리고 이전/다음 달 이동이 되는지(현재 달 이후로는 이동 불가) 확인합니다. 삭제 버튼과 최근 7일 점 표시도 확인합니다.
   - **메모**: 텍스트를 입력하면 "입력 중…" → 약 0.5초 후 "저장됨"으로 바뀌는지, 제목을 클릭해 수정하면 저장되는지 확인합니다. "+ 모듈 추가"로 메모를 여러 개 추가해 각각 독립적으로 저장되는지, 새 탭을 다시 열어도 내용이 유지되는지 확인합니다.
   - **뉴스**: 최초 로드 시 기사 목록이 표시되는지, 분야 칩을 여러 개 선택했을 때 조합된 결과가 표시되는지, "새로고침" 클릭 시 갱신되는지 확인합니다. 15분 이내 재방문 시 캐시된 데이터가 즉시 표시되는지(네트워크 요청 없이) Network 탭으로 확인할 수 있습니다.
   - **AI 브리핑**: API 키가 없는 상태에서 "AI 요약"을 누르면 키 입력 모달이 뜨는지 확인합니다. 유효한 동국 AI CHAT API Gateway 키를 입력하고 저장하면 자동으로 브리핑 생성이 시작되는지, 잘못된 키일 경우 오류 메시지와 함께 모달이 다시 뜨는지(401) 확인합니다. 브리핑에 취업/부동산/금융/IT 카테고리와 참고 자료 링크가 포함되는지, 특정 분야 칩만 선택한 상태에서 눌러도 결과가 달라지지 않는지(분야 필터와 무관하게 동작) 확인합니다. 같은 날 새 탭을 다시 열면 재요청 없이 캐시된 브리핑이 바로 보이는지 확인합니다.
   - **자주 방문**: 브라우저 방문 기록이 있는 상태에서 추천 목록이 표시되는지, 이미 등록된 바로가기와 겹치는 사이트는 제외되는지, `+` 버튼으로 바로가기에 추가하면 목록에서 사라지고 바로가기 카드에 반영되는지 확인합니다.
   - **모듈 배치**: 모듈 카드에 마우스를 올려 드래그 핸들(⠿)과 숨기기 버튼(×)이 나타나는지 확인합니다. 핸들을 드래그해 다른 모듈 앞/뒤로 옮기면 순서가 바뀌는지 확인합니다. ×를 누르면 해당 모듈이 사라지고(메모는 삭제 확인 후 완전히 삭제), 카드 목록 끝에 "+ 모듈 추가" 타일이 나타나는지 확인합니다. 타일을 눌러 숨긴 모듈을 다시 추가하면 목록 맨 뒤에 표시되는지 확인합니다. 새 탭을 다시 열어도 순서/표시 여부가 유지되는지 확인합니다(영속성 테스트, `moduleConfig` 키에 저장).
   - **설정 토글**: 우상단 "설정" 토글을 끄면 모듈 드래그 핸들이 동작하지 않는지(바로가기 순서 변경은 계속 가능한지), 다시 켜면 정상 동작으로 돌아오는지 확인합니다. 새 탭을 다시 열어도 토글 상태가 유지되는지 확인합니다(`dndEnabled` 키에 저장).
3. 저장된 데이터를 초기화하려면 DevTools Console에서 다음을 실행합니다.
   ```js
   chrome.storage.local.clear();
   ```
   이후 새 탭을 다시 열면 기본값(기본 바로가기 3개, 빈 할 일/메모, 새 뉴스 로드, 습관/자주 방문 모듈은 숨김)으로 초기화됩니다.

## 프로젝트 구조

```
newtab-extension/
├── manifest.json     # 확장 프로그램 설정 (Manifest V3)
├── newtab.html        # 새 탭 페이지 마크업
├── style.css          # 전체 스타일
├── storage.js         # chrome.storage.local을 감싼 Promise 유틸리티 (Store)
├── settings.js          # 드래그 정렬 켜기/끄기 전역 토글 (dndEnabled)
├── modules.js           # 모듈 메타 정보 및 설정(moduleConfig) 조회/저장 유틸리티
├── layout.js            # 새 탭 화면에서 모듈 드래그앤드롭 순서 변경, 숨기기/추가 로직
├── shortcuts.js         # 바로가기 목록
├── todo.js              # 할 일 목록
├── habit.js             # 습관 체크 및 월간 히트맵
├── news.js              # 뉴스 피드 및 AI 브리핑
├── notes.js             # 메모 카드 생성/저장 (다중 인스턴스)
├── mostvisited.js       # chrome.topSites 기반 자주 방문 추천
└── icons/                # 확장 프로그램 아이콘 (16/48/128px)
```

각 기능은 독립된 IIFE 모듈로 작성되어 있고, `Store.get(key, fallback)` / `Store.set(key, value)` / `Store.remove(key)`를 통해 `chrome.storage.local`에 데이터를 저장합니다. 모듈의 순서/표시 여부는 `moduleConfig` 키에 `[{ id, enabled }, ...]` 형태로 저장되며, 메모처럼 여러 개를 추가할 수 있는 모듈은 `notes:<고유id>` 형태의 인스턴스 id를 가집니다.

## 권한

- `storage` — 할 일, 습관, 메모, 바로가기, 뉴스 캐시, AI 브리핑용 API 키를 로컬에 저장하기 위해 사용합니다.
- `topSites` — "자주 방문" 모듈에서 최근 자주 방문한 사이트를 추천하기 위해 사용합니다.
- `host_permissions: https://news.google.com/*` — 뉴스 RSS 피드를 가져오기 위해 사용합니다.
- `host_permissions: https://factchat-cloud.mindlogic.ai/*` — AI 뉴스 브리핑 기능에서 동국 AI CHAT API Gateway(Claude)를 호출하기 위해 사용합니다.

## 참고

- 별도의 빌드 도구나 패키지 매니저가 필요하지 않습니다.
- 할 일, 습관, 메모, 바로가기, 뉴스 캐시 등 대부분의 사용자 데이터는 로컬 브라우저 저장소에만 남으며 별도 서버로 전송되지 않습니다.
- 예외적으로 **AI 브리핑 기능을 사용하면** 발급받은 API Gateway 키가 동국 AI CHAT 서버(`factchat-cloud.mindlogic.ai`)로 전송되며, Claude가 자체 `web_search` 도구를 통해 웹을 검색합니다. 이 기능은 "AI 요약" 버튼을 직접 누를 때만 동작하며, API 키를 입력하지 않으면 전혀 호출되지 않습니다. 키 발급 방법은 앱 내 "AI 요약 설정" 모달의 가이드 링크를 참고하세요.
