# 나만의 시작 페이지

바로가기, 할 일, 메모, 뉴스를 한 화면에 모은 크롬 새 탭 확장 프로그램입니다. 빌드 과정 없이 순수 HTML/CSS/JS로 작성되었으며, 모든 데이터는 `chrome.storage.local`에 저장됩니다. AI 뉴스 요약 기능을 사용할 경우에 한해 API 키와 검색 질의가 Google Gemini API로 전송됩니다(자세한 내용은 [참고](#참고) 섹션 참조).

## 기능

- **바로가기** — 자주 가는 사이트를 추가/삭제할 수 있는 바로가기 목록. 기본값으로 Gmail, Notion, GitHub가 등록되어 있습니다 (`shortcuts.js`).
- **할 일** — 항목 추가, 완료 체크, 삭제가 가능한 간단한 할 일 목록 (`todo.js`).
- **메모** — 자유롭게 적을 수 있는 메모장으로, 입력 후 자동 저장됩니다 (`notes.js`).
- **뉴스** — Google 뉴스 RSS 피드(`news.google.com`)를 불러와 최신 기사 8건을 보여줍니다. 전체/대한민국/세계/경제/IT·과학/연예/스포츠/건강 분야 칩으로 관심 분야를 선택하면 해당 분야 피드로 데이터를 가져오고 선택은 저장됩니다. 각 기사에는 언론사 파비콘 썸네일이 함께 표시됩니다. 15분간 캐시되며(분야별로 별도 캐시) 새로고침 버튼으로 즉시 갱신할 수 있습니다 (`news.js`).
- **AI 요약** — 뉴스 카드의 "AI 요약" 버튼을 누르면 Gemini API(무료 티어, `gemini-2.5-flash` 모델)가 자체 웹 검색 기능(Google 검색 그라운딩)으로 지난 24시간 내 취업/노동시장, 부동산/주거, 재테크/금융, IT/AI 분야의 주요 뉴스를 직접 검색해 카테고리별로 정리하고 출처 링크와 함께 브리핑을 생성합니다. RSS로 가져온 헤드라인 목록과는 별개로 동작하며(분야 칩 필터의 영향을 받지 않음), 최초 사용 시 [aistudio.google.com/app/apikey](https://aistudio.google.com/app/apikey)에서 발급받은 API 키를 입력하라는 모달이 뜨고, 키는 `chrome.storage.local`에만 저장됩니다. 버튼을 다시 누르면 그 시점 기준으로 새로 검색해 브리핑을 갱신합니다 (`news.js`).
- **모듈 배치** — 별도 설정 페이지 없이 새 탭 화면에서 바로 모듈(바로가기/할 일/메모/뉴스)을 관리합니다. 각 모듈에 마우스를 올리면 좌상단 드래그 핸들(⠿)과 우상단 숨기기 버튼(×)이 나타나며, 핸들을 드래그해 원하는 위치로 끌어다 놓으면 순서가 바뀝니다(바로가기의 드래그앤드롭과 동일한 방식). 숨긴 모듈은 카드 목록 끝의 "+ 모듈 추가" 타일을 눌러 다시 표시할 수 있습니다 (`modules.js`, `layout.js`).

## 로컬에서 실행하기 (개발자 모드)

1. 크롬 주소창에 `chrome://extensions`를 입력합니다.
2. 우측 상단의 "개발자 모드"를 켭니다.
3. "압축해제된 확장 프로그램을 로드합니다"를 클릭합니다.
4. 이 프로젝트 폴더(`newtab-extension`)를 선택합니다.
5. 새 탭을 열면 시작 페이지가 적용됩니다.

빌드 과정이 없으므로 파일을 수정한 뒤 바로 확인할 수 있습니다.

- **JS/CSS 수정 후**: `chrome://extensions`에서 이 확장 프로그램의 새로고침(⟳) 아이콘을 클릭한 다음, 열려 있던 새 탭을 닫고 다시 열어야 변경사항이 반영됩니다.
- **`manifest.json` 수정 후**: 위와 동일하게 새로고침이 필요합니다. 권한이나 `host_permissions`을 바꿨다면 크롬이 재승인을 요구할 수 있습니다.
- **HTML만 수정한 경우**: 새 탭을 다시 열기만 해도 반영됩니다 (확장 프로그램 새로고침 불필요).

## 테스트 방법

자동화된 테스트 스위트는 없으며, 수동으로 새 탭 페이지를 열어 기능별로 확인합니다.

1. 새 탭(Ctrl/Cmd+T)을 열고 페이지 위에서 마우스 우클릭 → "검사"로 DevTools를 엽니다.
   - **Console** 탭에서 에러가 없는지 확인합니다 (특히 `news.js`의 fetch 실패 로그).
   - **Network** 탭에서 새로고침 버튼 클릭 시 `news.google.com/rss...` 요청이 정상적으로 이루어지는지 확인합니다.
   - **Application → Storage → Local Storage**가 아닌 **Application → Storage → Extension Storage**(또는 `chrome.storage.local`)에서 저장된 값(`todos`, `note`, `shortcuts`, `news_cache:<분야>`, `news_pref_topics`, `news_ai_gemini_key`)을 직접 확인/삭제할 수 있습니다.
2. 기능별 체크리스트:
   - **바로가기**: "+ 추가" 버튼으로 이름/URL을 등록하고, 클릭 시 해당 사이트로 이동하는지, ×로 삭제가 되는지 확인합니다. 새 탭을 다시 열어도 목록이 유지되는지 확인합니다(영속성 테스트).
   - **할 일**: 항목 추가 후 Enter, 체크박스로 완료 처리, 삭제 버튼 동작, 남은 개수 표시(`n개 남음`)가 올바른지 확인합니다.
   - **메모**: 텍스트를 입력하면 "입력 중…" → 약 0.5초 후 "저장됨"으로 바뀌는지 확인하고, 새 탭을 다시 열어 내용이 유지되는지 확인합니다.
   - **뉴스**: 최초 로드 시 기사 목록이 표시되는지, "새로고침" 클릭 시 갱신되는지 확인합니다. 15분 이내 재방문 시 캐시된 데이터가 즉시 표시되는지(네트워크 요청 없이) Network 탭으로 확인할 수 있습니다.
   - **AI 요약**: API 키가 없는 상태에서 "AI 요약"을 누르면 키 입력 모달이 뜨는지 확인합니다. 유효한 Gemini API 키를 입력하고 저장하면 자동으로 검색·요약이 시작되는지, 잘못된 키일 경우 오류 메시지와 함께 모달이 다시 뜨는지 확인합니다. 브리핑에 취업/부동산/금융/IT 카테고리와 출처 링크가 포함되는지, 특정 분야 칩만 선택한 상태에서 눌러도 결과가 달라지지 않는지(분야 필터와 무관하게 동작) 확인합니다.
   - **모듈 배치**: 모듈 카드에 마우스를 올려 드래그 핸들(⠿)과 숨기기 버튼(×)이 나타나는지 확인합니다. 핸들을 드래그해 다른 모듈 앞/뒤로 옮기면 순서가 바뀌는지 확인합니다. ×를 누르면 해당 모듈이 사라지고, 카드 목록 끝에 "+ 모듈 추가" 타일이 나타나는지 확인합니다. 타일을 눌러 숨긴 모듈을 다시 추가하면 목록 맨 뒤에 표시되는지 확인합니다. 새 탭을 다시 열어도 순서/표시 여부가 유지되는지 확인합니다(영속성 테스트, `moduleConfig` 키에 저장).
3. 저장된 데이터를 초기화하려면 DevTools Console에서 다음을 실행합니다.
   ```js
   chrome.storage.local.clear();
   ```
   이후 새 탭을 다시 열면 기본값(기본 바로가기 3개, 빈 할 일/메모, 새 뉴스 로드)으로 초기화됩니다.

## 프로젝트 구조

```
newtab-extension/
├── manifest.json     # 확장 프로그램 설정 (Manifest V3)
├── newtab.html        # 새 탭 페이지 마크업
├── style.css          # 전체 스타일
├── storage.js         # chrome.storage.local을 감싼 Promise 유틸리티 (Store)
├── modules.js           # 모듈 메타 정보 및 설정(moduleConfig) 조회/저장 유틸리티
├── layout.js            # 새 탭 화면에서 모듈 드래그앤드롭 순서 변경, 숨기기/추가 로직
├── shortcuts.js         # 바로가기 목록
├── todo.js              # 할 일 목록
├── notes.js             # 메모
├── news.js              # 뉴스 피드
└── icons/                # 확장 프로그램 아이콘 (16/48/128px)
```

각 기능은 독립된 IIFE 모듈로 작성되어 있고, `Store.get(key, fallback)` / `Store.set(key, value)`를 통해 `chrome.storage.local`에 데이터를 저장합니다. 모듈의 순서/표시 여부는 `moduleConfig` 키에 `[{ id, enabled }, ...]` 형태로 저장됩니다.

## 권한

- `storage` — 할 일, 메모, 바로가기, 뉴스 캐시, AI 요약용 API 키를 로컬에 저장하기 위해 사용합니다.
- `host_permissions: https://news.google.com/*` — 뉴스 RSS 피드를 가져오기 위해 사용합니다.
- `host_permissions: https://generativelanguage.googleapis.com/*` — AI 뉴스 요약 기능에서 Google Gemini API를 호출하기 위해 사용합니다.

## 참고

- 별도의 빌드 도구나 패키지 매니저가 필요하지 않습니다.
- 할 일, 메모, 바로가기, 뉴스 캐시 등 대부분의 사용자 데이터는 로컬 브라우저 저장소에만 남으며 별도 서버로 전송되지 않습니다.
- 예외적으로 **AI 요약 기능을 사용하면** 발급받은 Gemini API 키가 Google 서버(`generativelanguage.googleapis.com`)로 전송되며, Gemini가 Google 검색 그라운딩을 통해 자체적으로 웹을 검색합니다(검색어와 검색 결과는 Google이 처리). 이 기능은 "AI 요약" 버튼을 직접 누를 때만 동작하며, API 키를 입력하지 않으면 전혀 호출되지 않습니다.
